## Was OpenAmer ist

Kein Chatbot, der nur redet. OpenAmer **führt aus** — auf deinem System, mit deinen Programmen.

- 🔒 **100 % lokal & privat** — keine Telemetrie, keine fremden Server, kein verstecktes Hochladen
- 🛠️ **120+ Werkzeuge** — Terminal, Browser-Automation, Dateien, E-Mail, Kalender, Datenbanken
- 🤖 **Handelt selbstständig** — recherchiert, schreibt, automatisiert mehrstufige Aufgaben
- 🧩 **Erweiterbar mit Skills** — wiederkehrende Abläufe werden zu dauerhaftem Können
- 🌍 **Mehrsprachig** — Deutsch, English, Español, Français, Italiano, Português, Русский, العربية, 中文, Türkçe, Bosanski, Shqip
- ⚡ **Schnell & schlank** — startet in Sekunden, läuft auch ohne dedizierte GPU
- 🧠 **Selbstverbessernd** — lernt aus eigenen Fehlern und schreibt sich weiter

**0 € Cloud-Kosten. 100 % lokal. 24/7 einsatzbereit.**
